# Day 23 – SQL Window Functions Intro

This project is part of my Data Analytics learning journey.

## Objective
To understand and apply SQL Window Functions for solving business-oriented analytical problems.

## Concepts Covered
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- LAG()
- PARTITION BY
- ORDER BY
- Common Table Expressions (CTEs)

- Developed 12 analytical SQL queries
- Generated outputs for each query
- Created a SQLite database

- Prepared an Excel workbook and PDF report

## Tools
- SQL
- SQLite
- Excel
- CSV
